# **App Name**: Dementia Assistant AI

## Core Features:

- Patient UI Simplification: A simplified interface on the PatientDashboard, offering an easy-to-navigate experience with high-contrast and large buttons.
- User Linking: Caregivers can input a Patient ID, linking accounts to coordinate care.
- User ID Display: Clearly display the unique user ID for both patients and caregivers for straightforward sharing and linking.
- Daily Planner: A feature displaying a clear, consistent daily routine, ensuring the patient can easily view their schedule.
- Memory Prompts: Showcases photos or stories followed by a simple prompt that will aid memory recall.
- AI Companion: The AI companion is designed to be conversationally and gently helpful when answering the patients simple questions using tool-augmented reasoning to retrieve the right detail.
- Care Coordination: Add and manage daily routines and memory prompts for patients, streamlining personalized care coordination.
- Medication Reminders: Reminders for medication, with personalized spoken prompts.
- Cognitive Games: Interactive games that use an AI model to adjust difficulty based on the player's performance and assist in brain engagement.
- Medicine Identification: A feature to identify the type of medicine by uploading a photo of the tablet pack, using AI for image recognition.
- Patient Monitoring: Care giver section to monitor the patients alerts, like the medicine, memory and other essential information that the caregiver must have and get the patients location and proximity alerts

## Style Guidelines:

- Primary color: Gentle blue (#90AFC5) evoking calmness and trust.
- Background color: Soft light-gray (#F0F4F7), almost white, for a serene and uncluttered feel.
- Accent color: Warm beige (#D9CBBF) that will act as gentle CTA
- Body and headline font: 'PT Sans' (sans-serif) gives a balance of modern feel with some warmth. 'PT Sans' would suit either headlines or body text.
- Use clear, simple icons to represent tasks, reminders, and options, optimizing the app's clarity for cognitive accessibility.
- A clean, minimalist layout prioritizing ease of use and reducing visual clutter; with dedicated sections for key functionalities.
- Very Subtle transitions to avoid triggering potential sensory overloads.
